Antes de tudo — criar contas
Comece aqui ▼
Criar conta no Google (se ainda não tiver)
Vá em google.com, clique em "Fazer login" no canto superior direito, depois em "Criar conta". Preencha nome, e-mail e senha. Guarde esse e-mail — vai usar em tudo.
O que é isso? O Google te dá ferramentas gratuitas: Gmail, Drive, Colab. Você vai usar tudo no projeto.
Criar conta no GitHub
Vá em github.com, clique em "Sign up". Coloque seu e-mail, crie uma senha, escolha um nome de usuário. Confirme pelo e-mail que chegar.
O que é o GitHub? É um lugar na internet onde você guarda e organiza seus arquivos de projeto. É tipo uma pasta online que todo mundo pode ver.
Criar conta no Kaggle
Vá em kaggle.com, clique em "Register". Pode entrar com a conta do Google (mais fácil). Depois vá em seu perfil → "Account" → "Create New API Token" e salve o arquivo kaggle.json que baixar.
O que é o Kaggle? É um site com tabelas de dados gratuitas pra baixar e usar em projetos. É de onde você vai pegar os dados do seu projeto.
Criar conta na Dadosfera
O link de acesso vai chegar no e-mail que você usou pra se candidatar à vaga. Procure um e-mail de suporte@dadosfera.ai com assunto "Acesse a Dadosfera | Registro". Clique em "Primeiro acesso".
O que é a Dadosfera? É a plataforma da empresa onde você vai subir e organizar seus dados. É onde os avaliadores vão ver seu trabalho.
Criar conta no Streamlit Community Cloud
Vá em streamlit.io, clique em "Sign up". Pode entrar com sua conta do Google ou do GitHub. Confirme pelo e-mail.
O que é o Streamlit? É onde você vai publicar seu "appzinho" de dados na internet, para qualquer pessoa acessar pelo link.

Criar repositório no GitHub
Entrega obrigatória ▼
Passo 1 — Entrar no GitHub e clicar em "New repository"
Entre em github.com com sua conta. No canto superior direito aparece um sinal de "+" (mais). Clique nele e depois em "New repository".
Passo 2 — Dar o nome certo ao repositório
No campo "Repository name", escreva exatamente assim (substituindo pelo seu nome):

SEUNOME_SEUSOBRENOME_DDF_TECH_042026

Exemplo: MARIA_SETE_DDF_TECH_042026
Atenção: tudo em letras maiúsculas, separado por underline (_), sem espaços.
Passo 3 — Configurar e criar
Deixe marcado "Public" (público). Marque a caixinha "Add a README file". Clique no botão verde "Create repository".
O que é um README? É um arquivo de texto que aparece na página do seu projeto. Funciona como uma capa: explica o que você fez, coloca links, fotos e instruções.

Item 0 — Planejamento (o mapa do projeto)
Item 0 ▼
O que você precisa fazer aqui
Criar uma imagem ou diagrama mostrando todas as etapas do projeto. Pense nisso como um mapa de tudo que você vai fazer, do começo ao fim.
Como fazer (do jeito mais fácil)
Vá em canva.com (gratuito), crie uma conta, escolha um modelo de "Fluxograma" ou "Kanban". Coloque as etapas: Planejamento → Dados → Limpeza → Análise → Dashboard → App → Vídeo → Entrega.
Dica: No Canva você arrasta e solta caixinhas prontas. Não precisa saber desenhar nada. Quando terminar, clique em "Baixar" e salve como PNG (imagem).
Como colocar essa imagem no GitHub
Entre no seu repositório no GitHub. Clique em "Add file" → "Upload files". Arraste a imagem que você baixou do Canva. Depois clique em "Commit changes" (botão verde).

Item 1 — Pegar os dados (o dataset)
Item 1 ▼
O que é um "dataset"?
Dataset é simplesmente uma tabela com muitas linhas de dados. Como uma planilha Excel gigante. O projeto exige que tenha mais de 100.000 linhas.
Qual dataset usar (recomendação)
Use o dataset Olist — são dados reais de um e-commerce brasileiro. Acesse: kaggle.com/datasets/olistbr/brazilian-ecommerce e clique em "Download" (vai pedir login no Kaggle).
O que tem nele? Pedidos, produtos, clientes, pagamentos, avaliações. Mais de 100 mil pedidos reais. Perfeito pro projeto.
Onde guardar o arquivo baixado
Vai baixar um arquivo .zip. Deixa ele na pasta Downloads do seu computador por enquanto. Na próxima etapa você vai enviar ele para o Google Colab (a nuvem).
4
Item 2 — Google Colab (abrir e usar)
Item 2 ▼
O que é o Google Colab?
É uma página do Google onde você escreve e roda código Python direto no navegador. Não precisa instalar nada no computador. É de graça e funciona como um caderno de anotações + calculadora ao mesmo tempo.
Comparação simples: é como o Google Docs, mas em vez de escrever texto, você escreve código. E quando aperta o botão play ▶, o código roda.
Passo 1 — Abrir o Colab
Vá em colab.research.google.com no navegador. Vai aparecer uma janela. Clique em "Novo notebook".
Passo 2 — Entender a tela
Você vai ver uma área cinza chamada "célula". É lá que você cola os códigos. Cada vez que quiser rodar um código, clica no botão ▶ à esquerda da célula (ou aperta Ctrl+Enter no teclado).
Passo 3 — Subir os dados do dataset
No menu lateral esquerdo do Colab, clique no ícone de pasta (📁). Depois clique em "Upload" (seta para cima). Selecione os arquivos .csv que estavam dentro do zip do Kaggle que você baixou.
Atenção: os arquivos somem quando você fecha o Colab. Isso é normal. Você vai subir de novo se precisar. Depois vamos guardar tudo no Google Drive para não perder.
Passo 4 — Primeiro código (só pra testar)
Clique na célula cinza e cole esse código exatamente assim:

import pandas as pd
df = pd.read_csv("olist_orders_dataset.csv")
df.head()

Depois clique ▶. Se aparecer uma tabela, funcionou!
O que esse código faz? Ele abre o arquivo CSV (que é sua tabela de dados) e mostra as 5 primeiras linhas. É só um teste pra ver se tudo carregou certo.

Item 2 — Subir dados na Dadosfera
Item 2 obrigatório ▼
O que é "subir dados na Dadosfera"?
É enviar sua tabela de dados para dentro da plataforma da empresa. Depois disso, você consegue fazer análises, gráficos e tudo mais por lá. É como importar uma planilha, mas numa ferramenta profissional.
Passo 1 — Entrar na Dadosfera
Acesse o link que chegou no seu e-mail (de suporte@dadosfera.ai). Entre com seu usuário e senha. Você vai ver o painel principal da plataforma.
Passo 2 — Ir para o módulo "Coleta"
No menu lateral esquerdo, procure por "Coletar" ou "Integrar". É por ali que você vai importar seus dados.
Passo 3 — Criar nova conexão com arquivo CSV
Clique em "Nova conexão" ou "Adicionar fonte de dados". Escolha a opção de arquivo CSV/planilha. Faça o upload do arquivo que você tem no seu computador.
Lembre-se: o arquivo tem que ter mais de 100.000 linhas. O dataset Olist tem isso, então fica tranquila.
Passo 4 — Tirar print da tela
Quando os dados carregarem, tire um print da tela mostrando a tabela carregada. No Windows: aperta a tecla "Print Screen" ou use a ferramenta de recorte (Win+Shift+S). Guarde essa imagem, vai usar no README.

Item 3 e 4 — Organizar e verificar qualidade
Item 3 e 4 obrigatórios ▼
Item 3 — Criar o dicionário de dados
É uma tabela explicando o que significa cada coluna. Por exemplo: "order_id = número do pedido", "customer_id = número do cliente", etc. Você faz isso numa tabela simples no README.
Pra que serve? Para qualquer pessoa que olhar seu projeto entender o que cada dado significa, sem precisar adivinhar.
Item 4 — Relatório de qualidade dos dados (no Colab)
Você vai rodar um código no Google Colab que analisa se tem dados faltando, erros, inconsistências. Cole essa célula no Colab e rode:
Código simples de qualidade:
print(df.isnull().sum())
Isso mostra quantos valores estão faltando em cada coluna. Tire um print do resultado.
Salvar o notebook do Colab
No Colab, vá em "Arquivo" → "Salvar cópia no Drive". Isso guarda o notebook no seu Google Drive. Depois você pode compartilhar o link dele.

Item 7 — Dashboard (gráficos)
Item 7 obrigatório ▼
O que é um dashboard?
É uma página com vários gráficos que mostram os dados de forma visual. Tipo um painel de controle. Você precisa fazer 5 gráficos diferentes.
Onde fazer os gráficos
Você vai fazer os gráficos na Dadosfera, no módulo de Visualização (que usa o Metabase). Procure no menu lateral o ícone de gráfico ou "Visualizar".
5 gráficos sugeridos (prontos pra usar)
1. Gráfico de barras — vendas por categoria de produto
2. Gráfico de linha — número de pedidos por mês
3. Gráfico de pizza — forma de pagamento mais usada
4. Tabela — top 10 produtos mais vendidos
5. Mapa ou gráfico de barras — pedidos por estado do Brasil
Tire prints de cada gráfico para colocar no README depois.

Item 9 — Criar o App no Streamlit
Item 9 ▼
O que é o Streamlit?
É uma ferramenta que transforma código Python num site interativo. Você escreve o código no Colab, copia para um arquivo, sobe no GitHub, e o Streamlit publica na internet automaticamente.
Passo 1 — Criar o arquivo app.py no GitHub
No seu repositório do GitHub, clique em "Add file" → "Create new file". Dê o nome app.py. Cole o código do app (posso gerar pra você).
Passo 2 — Criar arquivo requirements.txt
Crie outro arquivo chamado requirements.txt com o conteúdo:

streamlit
pandas
plotly

Esse arquivo diz pro Streamlit quais ferramentas instalar.
Passo 3 — Publicar no Streamlit Cloud
Entre em share.streamlit.io. Clique em "New app". Conecte sua conta do GitHub. Selecione seu repositório e o arquivo app.py. Clique em "Deploy". Em alguns minutos seu app estará no ar com um link!

Item 10 — Gravar o vídeo
Item 10 ▼
O que gravar no vídeo
Você vai gravar sua tela mostrando o projeto e falar explicando. Não precisa aparecer. Mostre: o GitHub, a Dadosfera com os dados, o dashboard, o app no Streamlit. Explique o que você fez em cada parte.
Como gravar a tela
No Windows: use o Xbox Game Bar (aperta Win+G, depois clique em gravar). Ou baixe o OBS Studio (gratuito) em obsproject.com. No Mac: use o QuickTime Player, Arquivo → Nova Gravação de Tela.
Como subir no YouTube
Entre em youtube.com, clique no ícone de câmera (canto superior direito) → "Fazer upload de vídeo". Selecione o arquivo gravado. No campo "Visibilidade", escolha "Não listado" (não público, não privado — só quem tem o link vê). Copie o link gerado e cole no README.
